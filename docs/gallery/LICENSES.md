# Figure assets

The layout, graphics and scripted demo accounts are original project assets. The displayed
claims were authored for the showcase. Source excerpts come from verified, stored receipts;
their source titles and domains are visible in the figure.

Typography uses [Inter](../../web/public/font-licenses/inter.txt) and
[Barlow Condensed](../../web/public/font-licenses/barlow-condensed.txt) under their bundled
SIL Open Font Licences. The editable HTML embeds those fonts for a standalone render.
Unicode emoji use the rendering system's emoji font. No downloaded emote artwork is used.

The numbered gallery uses actual product captures at 2×, original diagrams and measured
report graphics. The stream image comes from the original owned test recording. The
Twitch reply and Codex screen come from the owned test/build sessions. Account labels
are hidden in the Twitch crop and its long text is wrapped for legibility. The original
message is retained. Interface marks belong to their respective owners; this is an
independent project built for Twitch. Publisher excerpts retain their source attribution.
